# GetHub--Offline-Repo-Browser
GetHub – Offline Repo Browser is a Windows desktop application for browsing Git repositories without an internet connection. It lets you open local clones or repository archives, explore files and folders, read code with syntax highlighting, and review commit history, branches, and tags.

> **GetHub – Offline Repo Browser** is a Windows desktop application for browsing Git repositories without an internet connection. It lets you open local clones or repository archives, explore files and folders, read code with syntax highlighting, and review commit history, branches, and tags.

**Suggested README-style description**

| Section | Text |
|---|---|
| **Name** | GetHub – Offline Repo Browser |
| **Purpose** | Provide a GitHub-like browsing experience for local repositories, with no network or account required |
| **Key features** | File tree navigation, code viewer with syntax highlighting, commit history and diffs, branch/tag switching, README rendering, full-text search across files |
| **Target users** | Developers working in restricted, air-gapped, or low-connectivity environments, and anyone who wants fast local code review |
| **Platform** | Windows, .NET (Visual Studio 2022 solution) |
| **Privacy** | Fully local; no data leaves the machine |
